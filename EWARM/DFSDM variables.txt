; HARDWARE-CONFIRMED CHANNEL SELECTION — NON-NEGOTIABLE
; ══════════════════════════════════════════════════════════════════════════════
;
; Source: Board schematic mb1248-h747i-d04.pdf, sheet U21 (MP34DT05-A)
;
;   SB43 (LEFT SELECTION) = OPEN — LR is NOT pulled to GND
;   R213 (10K) pulls LR up to VDD/+3V3 rail
;   Therefore: LR = HIGH → RIGHT channel → PDM data on RISING edge of CLK
;
; DFSDM silicon routing (RM0399 Table, SAI4 MicPair1):
;   Rising  edge (D0) → DFSDM1_Channel0  ← CORRECT — this is our mic
;   Falling edge (D1) → DFSDM1_Channel1  ← wrong edge, empty slot, no data
;
; ACTIVE CHANNEL: DFSDM1_Channel0 (SITP=00, rising edge)
; DO NOT use Channel 1. Do not use falling edge. This is hardware-confirmed.
;
; Mic power: VDD = +3V3 via SB42 (closed solder bridge) — always on from CN2 USB.
;            SB41 = open (STPMIC1 MICBIAS path bypassed — no STPMIC1 init needed).
;
; Why CH1 produced CKABF (clock absence):
;   CH1 expects falling edge. The mic never outputs on falling edge when LR=HIGH.
;   PC1 appears stuck LOW from DFSDM's perspective → CKABF flag set.
;   CH0 (rising edge) sees real PDM transitions → no CKABF.
;
; Why DC=4501 was seen even on CH0:
;   DTRBS=5 → Sinc3 OSR=125 max output = ±61,035 → overflows int16_t (±32,767)
;   -61,035 cast to int16_t wraps: -61,035 + 65,536 = 4,501 (false DC, not real signal)
;   Fix: DTRBS=6 → max ±30,517 → fits int16_t cleanly. Code >> 8 shift then correct.

; ── SAI4 PDMCR ───────────────────────────────────────────────────────────────

; Expression:  SAI4->PDMCR
; IAR cast:    ((uint32_t*)0x58005444)[0]

; [OK] Expected and observed: 0x00000101
;   Bit 0  [PDMEN]  = 1  → PDM mode enabled
;   Bit 8  [CKEN1]  = 1  → Clock1 output (CK1 on PE2) enabled
;
; CRITICAL: PDMCR must be 0x00000101 BEFORE __HAL_SAI_ENABLE() is called.
;           If CKEN1=0, PE2 does not toggle → no clock to mic → CKABF on DFSDM CH0.

; ── SAI4 Block A CR1 ─────────────────────────────────────────────────────────

; Expression:  SAI4_Block_A->CR1
; IAR cast:    ((uint32_t*)0x58005404)[0]
; Debug global (confirmed readable): g_dbg_sai4_cr1 @ AXI SRAM
;
; [OK] Observed at init (before SAIEN): 0x00C10040
;   Bits[23:20][MCKDIV=12] = 12  → CK1 = PLL2P / (2×12) = 49142857/24 = 2.048 MHz ✓
;   Bit  17    [NODIV]     = 0   → clock divider active
;   Bit  4     [DS=4]      = 4   → data size 8-bit (PDM mode)
; MCKDIV=12 is forced by register override after HAL_SAI_Init (HAL computes 11 — wrong).

; ── SAI4 Clock math ──────────────────────────────────────────────────────────
;
;   PLL2P = HSE/M × N/P = (25/25) × 344/7 = 49,142,857 Hz
;   SAI4 CK1 = PLL2P / (2 × MCKDIV) = 49,142,857 / 24 = 2.048 MHz   (to mic PE2)
;   DFSDM CKOUT = APB2 / (2×(CKOUTDIV+1)) = 100 MHz / 50 = 2.000 MHz (to filter)
;   Difference = 2.4% — acceptable for voice recording
;   PCM rate = CKOUT / OSR = 2.000 MHz / 125 = 16,000 Hz ✓

;   3 seconds × 16,000 Hz = 48,000 samples = 96,000 bytes
