; ══════════════════════════════════════════════════════════════════════════════
; HARDWARE-CONFIRMED CHANNEL SELECTION — NON-NEGOTIABLE
; ══════════════════════════════════════════════════════════════════════════════
;
; Source: Board schematic mb1248-h747i-d04.pdf, sheet U21 (MP34DT05-A)
;         MP34DT05-A datasheet: LR=HIGH → RIGHT channel → FALLING edge
;         docs/DFSDM_Implementation_Notes.md Section 3 + 9
;
;   SB43 (LEFT SELECTION) = OPEN — LR is NOT pulled to GND
;   R213 (10K) pulls LR up to VDD/+3V3 rail
;   Therefore: LR = HIGH → RIGHT channel → PDM data on FALLING edge of CLK
;
; MP34DT05-A datasheet rule:
;   LR = LOW  → rising  edge → DFSDM1_Channel0 (SITP=00) ← empty on this board
;   LR = HIGH → FALLING edge → DFSDM1_Channel1 (SITP=01) ← OUR MIC
;
; ACTIVE CHANNEL: DFSDM1_Channel1 (SITP=01, falling edge)
; DO NOT use Channel 0 for data. Channel 0 is CLOCK MASTER ONLY (DFSDMEN + CKOUTDIV).
;
; SPICKSEL: SAI4_CK1 (PE2) is the mic clock — NOT CKOUT (PD3).
;   PD3 (CKOUT) is NOT routed to the mic on this board.
;   Required: SPICKSEL=11 (SAI4 internal silicon bridge).
;   HAL sets SPICKSEL=01 — must be overridden with CHEN clear/restore dance after
;   HAL_DFSDM_ChannelInit(). This fix is now permanently in MX_DFSDM1_Init (main.c).
;
; Clock master (Channel 0):
;   DFSDM1_Channel0->CHCFGR1 must have:
;     bit31 DFSDMEN=1  (global DFSDM enable)
;     bits[22:16] CKOUTDIV=24 → CKOUT = APB2(100MHz) / (2×25) = 2.0 MHz
;     CHEN=0  (Channel 0 is clock master only — no data role)
;   Expected Ch0 CHCFGR1 = 0x80180000
;
; Mic power: VDD = +3V3 via SB42 (closed solder bridge) — always on from CN2 USB.
;            SB41 = open (STPMIC1 MICBIAS path bypassed — no STPMIC1 init needed).

; ── SAI4 PDMCR ───────────────────────────────────────────────────────────────

; Expression:  SAI4->PDMCR
; IAR cast:    ((uint32_t*)0x58005444)[0]

; [OK] Expected and observed: 0x00000101
;   Bit 0  [PDMEN]  = 1  → PDM mode enabled
;   Bit 8  [CKEN1]  = 1  → Clock1 output (CK1 on PE2) enabled
;

;           If CKEN1=0, PE2 does not toggle → no clock to mic → CKABF on DFSDM CH1.

; ── SAI4 Block A CR1 ─────────────────────────────────────────────────────────

; Expression:  SAI4_Block_A->CR1
; IAR cast:    ((uint32_t*)0x58005404)[0]
; Debug global (confirmed readable): g_dbg_sai4_cr1 @ AXI SRAM
;
; [OK] Observed at init (before SAIEN): 0x00C10040
;   Bits[23:20][MCKDIV=12] = 12  → CK1 = PLL2P / (2×12) = 49142857/24 = 2.048 MHz ✓
;   Bit  17    [NODIV]     = 0   → clock divider active
;   Bit  4     [DS=4]      = 4   → data size 8-bit (PDM mode)
; MCKDIV=12 is forced by register override after HAL_SAI_Init (HAL computes 11 — wrong).
; During recording: bit 16 [SAIEN] = 1 ← must be 1 or mic has no clock.

; ── SAI4 Clock math ──────────────────────────────────────────────────────────
;
;   PLL2P = HSE/M × N/P = (25/25) × 344/7 = 49,142,857 Hz
;   SAI4 CK1 = PLL2P / (2 × MCKDIV) = 49,142,857 / 24 = 2.048 MHz   (to mic PE2)
;   DFSDM CKOUT = APB2 / (2×(CKOUTDIV+1)) = 100 MHz / 50 = 2.000 MHz (to filter, via PD3)
;   SAI4 CK1 and DFSDM CKOUT are INDEPENDENT clocks — 2.4% difference, acceptable.
;   PCM rate = CKOUT / OSR = 2.000 MHz / 125 = 16,000 Hz ✓
;   Note: SPICKSEL=11 means DFSDM samples data using the SAI4 clock (2.048 MHz), not CKOUT.

; 10. CHANNEL HISTORY (for reference — do not revert)
; ══════════════════════════════════════════════════════════════════════════════
;
;   CH3 (falling, SPICKSEL=11) → PC7 pulled HIGH → all-1s saturation (+61,035)
;   CH0 (rising,  SPICKSEL=11, DTRBS=5) → DTRBS overflow → DC=4501 (int16_t wrap)
;   CH1 (falling, SPICKSEL=01) → CKOUT/PD3 not connected → constant DC 0xFF119500
;   CH1 (falling, SPICKSEL=11, DTRBS=6) → CORRECT TARGET STATE ← current firmware
;
; Key lessons:
;   1. CKOUT (PD3) is NOT the mic clock on this board. SAI4_CK1 (PE2) is.
;      Always use SPICKSEL=11 (SAI4 bridge). SPICKSEL=01 gives dead DC output.
;   2. DC=4501 is NOT a channel problem. It is int16_t overflow from DTRBS=5.
;      Fix: DTRBS=6. The mic was alive; the shift was wrong.
;   3. CKABF=0xFF at boot is HARMLESS. It is a sticky flag set before SAI4 starts.
;      It clears automatically once DMA recording is running with correct clock.
;   4. LR=HIGH (R213 pull-up, SB43 open) = RIGHT channel = FALLING edge = Channel 1.
;      Never revert to Channel 0 for data. Channel 0 = clock master only.
